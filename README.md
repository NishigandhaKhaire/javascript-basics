# The Master Architect (Pure JavaScript)
## Bringing the Web to Life: DOM & Logic

Welcome to the **DOM & Logic** practice repository! This module transforms you from a "designer" to an "engineer" - you'll learn to control every pixel and behavior on a webpage using JavaScript.

---

## 📚 Module Overview

**JavaScript is the brain of the web.** While HTML is the skeleton and CSS is the skin, JS is the nervous system. In this module, you'll master the **Document Object Model (DOM)** - the programming interface that allows JavaScript to add, remove, and change HTML and CSS in real-time.

---

## 🎯 Key Learnings

| Topic | Description |
|-------|-------------|
| **DOM Hierarchy** | Mastering `querySelector` and `getElementById` to target any element |
| **Event Architecture** | Deep dive into `click`, `input`, and `submit` events |
| **Dynamic Styling** | Using `element.classList` to trigger CSS animations via JS |
| **State Management** | Using variables and arrays to track data locally |
| **Modern ES6+ Syntax** | Arrow functions, template literals, and destructuring |

## 🚀 Getting Started

### Prerequisites
- Basic HTML/CSS knowledge
- A modern web browser (Chrome, Firefox, Edge)
- A code editor (VS Code recommended)

### How to Use This Repository

1. **Clone or download** this repository
2. **Start with Part 1** - read the README, then open `index.html` in your browser
3. **Complete exercises** in `script.js` for each part
4. **Progress sequentially** - each part builds on the previous
5. **Finish with Homework** - the final project tests everything

### Running the Code
1. Open any `index.html` file directly in your browser
2. Open Developer Tools (F12) to see console output
3. Edit `script.js` and refresh the browser to see changes

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Nothing happens when I click | Check if event listener is added correctly |
| Elements not found | Verify ID/class names match exactly |
| Console shows errors | Read the error message - it tells you the line number |
| Changes don't show | Make sure you saved the file and refreshed browser |
